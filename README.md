# Road Traffic Accident Analysis Using Python

## Project Overview
This project analyzes road traffic accident data to identify patterns related to accident severity, driver demographics, vehicle types, road conditions, weather, and other contributing factors.

## Objectives
- Analyze accident severity and accident frequency.
- Explore accident patterns by day of the week.
- Study driver age groups and gender.
- Examine accident distributions by vehicle type.
- Explore road, lighting, and weather conditions.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The dataset contains 12,316 records and 32 columns related to road traffic accidents.

## Project File Structure
- `RTA_Accident_Analysis_pythonproject(2).ipynb` — analysis notebook
- `RTA_Dataset.csv` — accident dataset

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Ensure the dataset filename in the notebook matches the CSV file.
5. Run the notebook cells in order.

## Key Learning Outcomes
- Exploratory data analysis (EDA)
- Data visualization
- Working with categorical variables
- Identifying patterns in accident data

*Note: Findings describe patterns in the dataset and do not necessarily establish causation.*
